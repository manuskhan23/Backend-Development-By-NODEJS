## 🎯 About

This repository contains comprehensive backend development coursework, following a structured curriculum. It covers everything from Node.js fundamentals to building full REST APIs with Express.js, database integration, and deploying production-ready backends.

---

## 📚 Course Curriculum

| Module | Topic | Key Technologies |
|--------|-------|------------------|
| 1 | **Node.js Fundamentals** | Core modules, event loop, npm |
| 2 | **Express.js** | Routing, middleware, templates |
| 3 | **MongoDB & Mongoose** | Schemas, models, CRUD, aggregation |
| 4 | **EJS Templating** | Server-side rendering, layouts |
| 5 | **SQL & Databases** | Relational DB concepts |
| 6 | **Full Project** | Complete backend application |
| 7 | **TailwindCSS for Frontend** | Utility-first CSS for UI |

## 🚀 Getting Started

### Prerequisites
- **HTML, CSS, Basic JavaScript** (recommended prior knowledge)
- Node.js 18+
- MongoDB (local or Atlas)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/manuskhan23/Backend-Development-By-NODEJS.git
cd Backend-Development-By-NODEJS

# Install dependencies
npm install

# Run the project
npm start
```
